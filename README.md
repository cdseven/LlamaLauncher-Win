# Llama Launcher

Run AI models locally on your own PC — no cloud, no subscription, no hassle.

---

## What It Does

Got a gaming PC? A humble laptop? A supercomputer? Llama Launcher gives you a simple, friendly interface for running AI language models on your own hardware — chat with them, ask questions, or just experiment. No command line required, and no complicated setup — it can even download what it needs automatically.

Built on [llama.cpp](https://github.com/ggerganov/llama.cpp) for efficient local text generation inference.

Pair it with a feature-rich front-end like [Open WebUI](https://github.com/open-webui/open-webui) or [TypingMind](https://www.typingmind.com/) and the possibilities are endless — research, coding assistance, agentic workflows, plugins, and much more.

---

## Requirements

- Windows 10 or later *(Linux version planned)*

That's it. No Python installation required. No manual llama.cpp setup required.

**GPU Support:** Llama Launcher was built and tested with an Nvidia GPU, but is designed to support AMD, Intel, and Vulkan engines in addition to CUDA. CPU-only operation is also supported.

---

## Installation

1. Download the latest zip file from the [Releases](../../releases) page.
2. Unzip it — you'll get a folder called `LlamaLauncher-Win` containing everything you need.
3. Open the `LlamaLauncher-Win` folder and run `LlamaLauncher.exe`.
